# 🚫 Cringe Vaccine – Save Your LinkedIn Feed!  

Tired of scrolling through engagement bait, self-congratulatory nonsense, and posts that make you lose faith in humanity? **Cringe Vaccine** is here to help!  

This Chrome extension **uses AI to filter out cringe-worthy content** from your LinkedIn feed in real time—so you only see posts that actually matter. No more fake hustle stories, exaggerated success posts, or shameless self-promotions. Just clean, valuable content.

## 🛠 How It Works  

The extension works seamlessly in the background while you browse LinkedIn:  

1. **Scans Your Feed** – Detects new posts as they appear.  
2. **AI-Powered Filtering** – Sends the post to an AI model (via an API) that classifies it based on "cringe" criteria (engagement bait, overly promotional content, etc.).  
3. **Hides the Cringe** – Blurs posts that are classified as low-value, keeping your feed cleaner and more relevant.  
4. **User Control** – Users can modify filtering preferences and customize settings directly in the `content.js` file.

## 🚀 Getting Started  

### 🔧 Install & Run Locally  

To use Cringe Vaccine on your Chrome browser:  

1. **Clone the Repository**  
   ```sh
   - git clone https://github.com/ikisla/cringe-vaccine.git
   - cd cringe-vaccine
    ```

1. **Loading in browsers**  

```sh
- Open Chrome browser and navigate to the Extensions page by typing chrome://extensions/ in the URL bar.
- Enable Developer Mode in the top-right corner.
- Click on the Load unpacked button.
- Select the folder where the extension files are located (cringe-guard folder).
```
